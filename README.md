# StudentScore-Analyser

A simple JavaScript program that processes an array of student scores using loops to calculate statistics and performance metrics without relying on built-in helper functions like `Math.max()` or `Math.min()`.

## Features

- **Score Logging**: Prints each individual student's score along with their index.
- **Total Calculation**: Sums up all the scores in the array.
- **Average Calculation**: Computes the overall class average score.
- **Highest Score Finder**: Determines the maximum score using a comparison loop.
- **Lowest Score Finder**: Determines the minimum score using a comparison loop.
- **Pass/Fail Tracker**: Counts how many students passed or failed based on a defined passing threshold (set to 50).
